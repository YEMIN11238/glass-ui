# 演示素材与验证范围

这些素材来自 2026-10-13 的实际运行，没有生成式图片、第三方产品截图、用户项目或个人账号内容。

## 网页素材

- `web-demo.png`：`assets/web/demo.html` 在 Chromium 中的真实页面截图，1280 × 900，液态基础效果 / 浅色 / 85%。
- `liquid-light.png`、`frosted-light.png`、`system-light.png`：同一演示在浅色下的真实截图裁切；两种玻璃都使用 85%，实色保留该值但不应用透明度。
- `web-switching.gif`：12 个实际操作状态的截图序列，按顺序播放；960 × 675，约 14 秒。演示三材质、浅深色与 0 / 35 / 85 / 100% 透明度。
- 裁切、等比例缩小与 GIF 编码只用于组织实际截图，没有重绘、替换或生成玻璃效果。截图使用仓库自带 CSS 与控制器，没有安装 `liquid-glass-react`。

网页背景是演示页自身的渐变与文字，用于观察 CSS 模糊。它不读取桌面，基础液态模式没有光学折射。实际 UI 切换、输入、按钮、实色控件隐藏和统一状态另行验证。

## 原生实际应用

`native-application.png` 是实际运行的隔离 Electron 应用窗口截图，内容由维护者为这次验证制作。运行环境是 macOS 27.0.1、macOS SDK 27.0、Electron 44.0.0。截图中的控件使用本仓库原生桥与适配器；它没有包含 AIPM 工作台资料或任何第三方产品界面。

构建与操作检查包括三种材质、浅深色、统一透明度 0 / 82 / 100%、主题继承、窗口背景 alpha 与原生视图诊断。液态层诊断包含 `NSGlassEffectView`；毛玻璃诊断包含 `NSVisualEffectView` 和 behind-window 配置。

**原生桌面透底的视觉项尚未通过。** 本次窗口截图没有呈现后方真实测试窗口。限定演示区域的 macOS 屏幕采集返回 `could not create image from rect`，未生成可验证的合成画面；原因尚未确定。原生层参数正确不能替代视觉证据，所以这个图片只说明应用与配置实际运行，不能作为原生透底或光学折射成功的宣传图。

补充原生效果素材时，应在真实浅色、深色与高对比背景前移动窗口并采集实际合成画面，再按 [验收参考](../../references/verification.md) 检查。不要把 Web 渐变、灰底窗口截图或生成图混作桌面透底证明。
