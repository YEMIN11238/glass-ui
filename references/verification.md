# 验收与常见故障

## 以真实显示作为完成条件

对网页组件，放在有清楚边界的蓝/橙色块、图片或文字上检查；图案留在测试页面，不进入宿主产品。对桌面窗口，把实际窗口移到彩色桌面或另一窗口上，观察颜色随位置变化。原生布局检查可用于解释原因，不能代替视觉效果。

一次有效检查应覆盖：

1. 液态和毛玻璃在同一背景、同一透明度和色调下有可辨区别。液态偏光滑和高光；毛玻璃背景边缘扩散，并有很轻的细纹理。
2. 只有一个透明度滑杆，两种玻璃共享同一个值。实色时该区域不可见、不可点击或聚焦、辅助技术不读取，但占用尺寸不变。没有多余滑杆说明或可见状态行。0、中间、100 的填充明显变化；最高毛玻璃透明度仍应模糊背景。
3. 只有当前材质的一组颜色控件可见：玻璃为浅色/深色，实色为跟随系统/浅色/深色。从玻璃选深色后切实色仍是深色；实色手动浅色切回玻璃仍是浅色。切换材质不改变保存的 theme 或 transparency。
4. 跟随系统在全部材质实时变化，切回玻璃不把 system 偏好改成手动值；玻璃两个按钮显示当前解析色。手动浅深色跨材质保持固定。真实 OS 状态仍更新，不能用手动选择伪造 `data-system-theme`。可通过宿主测试事件模拟，说明模拟与实际系统验收的区别。
5. 快速拖动或快速切换主题后关闭再打开，恢复最后值。旧偏好按活动材质迁移为统一 theme 和 transparency，实色透明度迁移优先液态值再磨砂值；非法旧值仍拒绝。保存失败可恢复且不会让下一次保存永久阻塞。Web 退出持久化按其宿主生命周期验收。
6. 背景层不拦截点击；滑杆和色调选项可用键盘操作。小文字在亮、暗、彩色背景上能阅读，输入框、菜单、弹窗和文档编辑区保持清晰。
7. 两项/三项颜色选项切换时高度、外观面板尺寸和弹窗位置不变。等待应用时控件仍禁交互，视觉不整体变淡再恢复。毛玻璃转实色没有透明空帧；实色转玻璃在网页降低填充前已有原生背景。快速切换或交接失败后，原生层与网页层保持同一成功状态。不要用全屏染灰遮罩掩盖闪烁。
8. macOS 整窗接入保留红黄绿按钮的完整边界与原有位置。切材质、改透明度、缩放/最大化/还原、隐藏后显示和退出全屏后，检查实际按钮 frame 或正常窗口视觉；getter 只返回自定义配置，不能证明没有顶边裁切。全屏和已知过渡期间遵从系统布局，关闭窗口后无维护回调残留。

渲染/构建失败、按钮已选中、原生层已创建，均不是视觉验收完成。明确记录尚未验证的平台或效果。

## 对症检查

| 现象 | 先检查 |
| --- | --- |
| 两种模式都只有灰色 | 根页面/父容器是否盖了实色；CSS `color-scheme` 画布；原生透明窗口与 WebContents 的底色；当前背景是否本来就是灰色。 |
| CSS 有 blur，但桌面没有模糊 | 浏览器 CSS 只能采样网页内容。Electron/macOS 需要独立 behind-window 原生层。 |
| 拉满仍很厚 | 额外白/黑填充与多个面板叠加；原生材质自身的染色。优先减少填充并实测材质，不仅改标签或按钮。 |
| 拉满后失去磨砂 | 原生效果 alpha 降得太低，未模糊的背景大量混回。保留扩散强度，细颗粒仅作补充。 |
| 字和图标也淡了 | 把 `opacity` 用到了窗口或包含内容的容器。只调独立背景层和颜色填充的 alpha。 |
| 单组件改坏全站主题 | 把作用域样式写成 `:root/body/button` 等全局规则。用组件容器、命名空间和宿主 token。 |
| 外观预览总变暗 | 设置 dialog 的 `::backdrop` 正在染灰/模糊整个页面。只清理外观预览遮罩。 |
| 重启恢复旧值 | 请求还在 renderer 的延迟队列、写入乱序、关闭没有 flush，或存储 key 被另一组件共用。 |
| 手动颜色被系统变化覆盖 | 用户 theme 与真实 OS 状态混用；应分别保留，按选择解析全部材质的实际颜色。 |
| 切材质后颜色或透明度跳变 | 仍有分材质偏好，或 setMode 同时改 theme / transparency；材质切换只修改 mode。 |
| 切材质时设置框跳动 | 透明度区域被 display:none 或卸载，颜色组增减改变行高，或弹窗每次按内容重新居中。保留布局槽位与稳定锚点。 |
| 毛玻璃转实色闪出背景 | 原生模糊先移除，而网页尚未完成不透明绘制；协调两层 ready 与提交。 |
| 红黄绿按钮贴顶或部分裁切 | 原生 appearance/vibrancy 更新可能重新布局隐藏标题栏。对宿主明确的 frameless/hiddenInset 窗口，可用 [原生参考](electron-macos.md) 的可选 helper 重申已有自定义 Point；getter=null 不暴露实际 hiddenInset 布局，不能自动传 null 保持。null 仅用于宿主要求系统默认/reset，全屏过渡遵从系统。 |
| 页面鼠标点不到 | 装饰玻璃层拦截事件、透明覆盖层层级错误，或原生背景视图不是 passthrough。 |
| 截图和实际窗口不一致 | 原生窗口截图可能丢失外部 backdrop；打开 Electron DevTools 也可能使透明窗口行为变化。关闭后用正常窗口再看。 |

## 降级

浏览器不支持 `backdrop-filter` 时，使用更实的表面保证可读性。用户启用“降低透明度”或减少动态效果时尊重系统设置。不能实现真实桌面玻璃的平台，保留可用的网页内玻璃或系统实色页面，并明确边界。

资源中的 smoke palette、细纹理和磨砂 alpha 下限可被宿主设计 token 覆盖；不要为了保证截图外观一致而固定背景颜色或采集用户桌面作为贴图。
